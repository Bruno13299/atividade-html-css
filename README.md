# 🕷️ O Incrível Homem-Aranha | Projeto HTML & CSS

Um projeto desenvolvido com **HTML5 e CSS3**, inspirado no universo do Homem-Aranha, com o objetivo de colocar em prática conceitos fundamentais do desenvolvimento web.

## 💻 Sobre o projeto

O projeto consiste na criação de uma página temática sobre o Homem-Aranha, apresentando informações sobre Peter Parker em uma interface organizada e visualmente inspirada no personagem.

A proposta foi unir estrutura, criatividade e estilização, transformando conhecimentos adquiridos em sala de aula em um projeto prático.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação e organização do conteúdo.
- **CSS3:** estilização e personalização da página.

## 📁 Estrutura do projeto

```text
atividade-html-css/
│
├── index.html
└── style.css
```

## 🎯 Funcionalidades e recursos

- Estruturação de conteúdo com HTML.
- Estilização utilizando CSS externo.
- Personalização de cores e fontes.
- Aplicação de bordas e espaçamentos.
- Organização dos elementos da página.

## 📚 Aprendizados

O desenvolvimento deste projeto permitiu aprimorar conhecimentos em HTML e CSS, compreender melhor a construção de páginas web e explorar diferentes possibilidades de organização e estilização.
